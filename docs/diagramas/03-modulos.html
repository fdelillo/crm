Mapa de módulos

La base actual habilita los módulos comerciales y financieros definidos en las diez specs.

Se agrupan proyectos + presupuestos, dinero + cuentas corrientes + cheques, y reportes + importación para respetar el presupuesto de nueve nodos.

Cómo leer esta vista

  • El catálogo industrytemplate existe, pero el arranque usa NoopSeeder: el sembrado de configuración completa pertenece a la spec 002.
  • Los grupos representan capacidades; no afirman dependencias de código entre módulos futuros.
  • Orden sugerido: 001 → 002 → 003; 004 → 005; 006 → 007 → 010; 009; 008.

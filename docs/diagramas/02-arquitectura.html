Arquitectura general

La API y el worker comparten proceso; la SPA embebida está prevista para el mismo binario.

La raíz / responde hoy 503: SPAUnavailableHandler. La API no depende de que el frontend esté compilado.

Cómo leer esta vista

  • El binario también incluye el subcomando migrate y comandos operativos. El rol de migraciones es distinto del rol del pool de runtime.
  • Los emails se encolan en PostgreSQL dentro de la transacción de negocio; el worker entrega por SMTP después.
  • La SPA y la API compartirán origen. El atlas documental se sirve por separado de la aplicación.

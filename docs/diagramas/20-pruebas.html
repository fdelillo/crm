Garantías por nivel de prueba

Cada nivel verifica un alcance mayor; la base real es necesaria para comprobar roles, políticas y concurrencia.

La figura no afirma porcentajes de cobertura ni cantidad de tests. Los E2E de navegador del frontend son diseño previsto.

Cómo leer esta vista

  • El harness crea PostgreSQL 18 con bootstrap y migraciones, y el runtime se prueba como crm_app. Un superusuario invalidaría la comprobación de RLS.
  • Los tests de servicio pueden sustituir Mailer, ObjectStorage y reloj; no sustituyen PostgreSQL, router ni middleware. Los adaptadores tienen sus propios tests reales.
  • Las reglas de repositorio detectan SQL y cambios de rol fuera de sus fronteras. Los benchmarks de rendimiento se ejecutan aparte con el tag bench.
  • La constitución exige tests antes del código en el núcleo financiero. Vitest/Testing Library/MSW/Playwright son decisiones de frontend todavía pendientes en parte.

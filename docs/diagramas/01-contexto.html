Contexto del sistema

Dos perfiles operan el CRM, que delega correos y almacenamiento de archivos.

El alcance comercial y financiero procede de las specs; el backend actual implementa la base de empresas e identidad.

Cómo leer esta vista

  • Una cuenta de usuario pertenece a una empresa; el MVP no contempla membresía en varias empresas.
  • El correo notifica verificación, recuperación e invitaciones. Los clientes y proveedores son terceros del negocio, sin acceso propio previsto en el MVP.
  • WhatsApp aparece en el alcance de presupuestos; no se representa como una integración API existente.

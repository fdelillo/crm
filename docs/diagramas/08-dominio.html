Modelo conceptual del negocio

Dos vistas para distinguir gestión comercial y los tres libros financieros.

EspecificadoHTML con CSS y SVG inlineVista doc-wide · audiencia técnica

Diseño especificado: esta vista no afirma implementación ni aprobación de todos sus detalles. Las fuentes conservan su estado original.

Modelo comercial

Terceros, proyectos y presupuestos forman el núcleo comercial especificado.

Cada proyecto tiene una etapa; una etapa puede agrupar muchos proyectos. Campos resumidos: no son columnas SQL.

Los tres libros financieros

Caja, cuentas corrientes y costos de proyecto registran aspectos distintos de una operación.

CostAllocation se muestra como agregado independiente: asigna costos al proyecto cuando se genera el gasto, no cuando se paga.

Cómo leer esta vista

  • Estas entidades vienen de docs/modelo-dominio.md y las specs 002–010. No representan tablas ya creadas.
  • Toda entidad de negocio pertenece a una empresa. En estas vistas se omiten las relaciones repetidas a Tenant para facilitar la lectura.
  • Cada operación financiera modifica sus registros relacionados de forma atómica. Los saldos se derivan de movimientos vigentes.
  • Se omiten adjuntos, catálogo, categorías, compras, cheques, extractos y plan de cobros en estas vistas base; sus vistas se encuentran en los temas de negocio previsto.

Circuito comercial completo

Ejemplo de trabajo por proyecto, desde una consulta hasta el cierre y el saldo final.

El circuito es un ejemplo del rubro inicial. Las etapas se configuran por empresa y el cierre no exige automáticamente saldo cero.

Cómo leer esta vista

  • Antes de aprobar, un proyecto nuevo no genera deuda por su presupuesto. La aprobación fija el monto y genera la deuda total; una seña es otra operación.
  • El cliente confirma por fuera del sistema; un usuario registra la aprobación. WhatsApp abre wa.me con enlace al PDF, no una integración bancaria ni una aprobación online.
  • Compras y cargos generan costos cuando corresponde. Los pagos cancelan deudas, sin imputar otra vez el mismo costo.
  • Cerrar ganado con saldo pendiente muestra advertencia pero está permitido. Pasar a perdido no elimina una deuda existente.

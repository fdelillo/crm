Tipografía: ui-sans-serif, system-ui, -apple-system, Segoe UI, Roboto, Helvetica Neue, Arial, sans-serif. Nombres y títulos: familia del sistema, peso 600. Etiquetas técnicas: ui-monospace, SFMono-Regular, Consolas, monospace (adaptación documental). Sin fuentes tipográficas web ni recursos remotos de renderizado. Las referencias de código y diseño son enlaces de GitHub que requieren conexión. Tema claro. Bordes de 6–8 px, sin sombras.

El estilo se conserva junto al atlas. No se modifica el estilo compartido de la instalación del plugin ni se crea un perfil global.

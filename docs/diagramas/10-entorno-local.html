Entorno local de desarrollo

Go corre en el host y PostgreSQL, MinIO y Mailpit en contenedores con puertos de loopback.

Vite no existe aún en este checkout. El certificado de mkcert habilita cookies Secure en HTTPS local.

Cómo leer esta vista

  • docker compose up -d --wait levanta servicios y crea el bucket local. Luego crm migrate up usa DATABASE_MIGRATION_URL como crm_owner.
  • Con TLS_CERT_FILE y TLS_KEY_FILE, crm serve escucha HTTPS local. /healthz comprueba vida; /readyz valida la disponibilidad y la versión del esquema.
  • Sin frontend embebido, / devuelve 503. Vite + API está documentado como modo futuro, con proxy del mismo origen en desarrollo.
  • El hosting de producción permanece por definir: esta vista no afirma infraestructura desplegada. PostgreSQL tiene volumen pgdata y MinIO volumen miniodata.

Contrato de la API

El YAML es la fuente de verdad; el backend se escribe a mano y su conformidad se verifica en tests.

Solo existe hoy el contrato de 001. Los contratos siguientes y la generación del cliente frontend se agregan al desarrollar esas etapas.

Generación del acceso SQL

sqlc produce el código de consultas a partir de SQL y migraciones.

El SQL es la fuente del acceso a datos. Los archivos generados se versionan y el check detecta desactualización.

Cómo leer esta vista

  • La respuesta HTTP se valida contra la operación declarada. El request se valida cuando la respuesta es 2xx, para permitir tests negativos deliberadamente inválidos.
  • 404 de ruta desconocida y 405 global se validan contra Problem; 405 exige Allow. Los demás status deben existir en la operación.
  • Un guard compara rutas chi y paths OpenAPI. Una ruta nueva necesita contrato, test de comportamiento y caso de aislamiento.
  • Los componentes compartidos viven en 001 y los contratos futuros los referenciarán con $ref. La intersección de tipos por spec es diseño del frontend, con detalles Proposed.
